BEISPIELE FÜR status.json
=========================

Kurzanleitung
-------------
Diese Datei ist nur eine Vorlagensammlung – sie wird vom Programm NICHT gelesen.
Zum Anzeigen einer Meldung den gewünschten Block kopieren und damit den Inhalt
von "status.json" ersetzen (im selben Ordner), dann committen und pushen.

Die Meldung erscheint innerhalb weniger Minuten in jeder laufenden
Installation und kann vom Nutzer weggeklickt werden.

Felder
------
  active    true  = Meldung anzeigen
            false = nichts anzeigen (Meldung bleibt für später gespeichert)

  id        Kennung der Meldung. WICHTIG: Eine NEUE id sorgt dafür, dass die
            Meldung auch bei Nutzern wieder erscheint, die die vorherige
            bereits weggeklickt haben. Bewährt: Datum + Stichwort,
            z. B. "2026-08-03-pdf-fehler".

  level     "info"    = neutraler Hinweis
            "warning" = rot hervorgehoben (Störungen, Datenverlust-Gefahr)

  title     Fette Überschrift (optional, aber empfohlen)

  message   Der eigentliche Text. Anführungszeichen im Text mit \" schreiben.

Faustregel: sagen, WAS los ist, WAS der Nutzer tun soll und ob er WARTEN muss.
